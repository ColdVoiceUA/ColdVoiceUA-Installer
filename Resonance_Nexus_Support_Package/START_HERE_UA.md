# Готовий пакет вихідного коду Resonance для Nexus

Звірку наданих матеріалів завершено:
- EXE: ColdVoiceUA_Resonance_DEMO_v1.3.0.0.exe, 42 091 934 байти (за звітом).
- 571 заміна англійських аудіоресурсів; DEMO ID збігаються з маніфестом.
- Витягнутий INSTALL.ps1 збігається з runtime підготовленого v3-коду.
- Хеші файлів із actual_exe_materials перевірені незалежно.
- Сам EXE та аудіо тут не надавалися: повний C#-бінарний збіг не доведений.

Що завантажити на GitHub:
1. Розпакуйте цей ZIP: отримаєте папку Resonance_Nexus_Support_Package.
2. У наявному репозиторії ColdVoiceUA/ColdVoiceUA-Installer відкрийте головну папку.
3. Add file → Upload files → перетягніть всю папку Resonance_Nexus_Support_Package.
4. Commit changes. Стару папку ColdVoiceUA_Nexus_Support_Package для Townfall не видаляйте.
5. Відкрийте нову папку на GitHub і скопіюйте її URL для Nexus Support.

Це матеріали перевірки, а не оновлення програми й не пакет для встановлення у гру.
Не потрібно повторно запускати COLLECT_REVIEW.bat для вже перевіреного EXE.
Для нового, іншого EXE потрібен окремий звіт.

Для Nexus додайте посилання на папку коду та назву завантаженого EXE,
його SHA256, посилання на сторінку моду та прохання ручної перевірки.
README_REVIEW_EN.md містить опис інсталятора й інструкції збирання англійською.
Поточний вміст GitHub із цього середовища отримати не вдалося; ця папка додає
окремі матеріали Resonance без підміни старих матеріалів Townfall.
